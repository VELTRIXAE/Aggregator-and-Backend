# VELTRIXAE contract integration

The contracts project is VELTRIXAE/Contract. Its authorized AMM deployment was completed and verified on 2026-11-02 using source commit 133b18d00505108c26382cb44045abab48b51882. The [real completed manifest](evidence/contracts-testnet-deployment-2026-11-02.json) and exact optimized WASM are preserved in docs/evidence. Factory/Router/Pair required signatures match the backend's pinned Soroswap ABI; the soroswap configuration slot names this ABI, not ownership of the VELTRIXAE deployment.

`config/testnet.json` now contains those real Factory/Router IDs and deployed WASM hashes, network=testnet, veltrixae=null and assets=[]. The separate aggregator is absent and must not be represented by the AMM Router ID. Its configuration requires a real aggregator and aggregatorWasmHash after separate deployment/initialization verification. No pool/liquidity is present; a live quote or full swap cannot yet be verified.

Run `npm run verify:deployment` to check Testnet passphrase, code hashes, router factory, active aggregator Soroswap router and pool identity/reserves. Metadata asset entries are contract plus either native=true or a valid code and Ed25519 issuer; the classic asset must derive to that contract on Testnet. No issuer trust endorsement is made.

The preserved aggregator expects swap_exact_tokens_for_tokens(token_in, token_out, amount_in, amount_out_min, distribution, to, deadline) or swap_tokens_for_exact_tokens(token_in, token_out, amount_out, amount_in_max, distribution, to, deadline). Distribution is a vector of structs: protocol_id is the u32-backed Soroban enum (Soroswap=0), path is Address[], parts is u32, bytes is Option<Vec<BytesN<32>>> (None for Soroswap). Deadline is Unix seconds u64. Recipient authorization and admin authorization remain in Rust.

`POST /api/v1/swaps/prepare` accepts fresh quote parameters and the wallet public account. It validates the configured aggregator, builds a single-route operation, fetches the account sequence, simulates the full invocation, rejects restoration requirements, assembles resource fees and auth entries, and returns unsigned XDR. Quote and simulation ledgers must agree. `StellarChain.swapOperation` encodes the underlying single-route invocation. The connected wallet must build with its public account and sequence, simulate the actual invocation, inspect authorization and resource fees, assemble, sign and submit. Router quote simulation alone does not validate balances or swap authorization. Do not sign an expired quote or allow a client to substitute the reviewed contract ID. Transaction lookup reports the resulting hash.

Contract ABI, artifact hash and initialized router/admin state must all be reviewed. A code hash match is not a security audit. Changes to pause state or code require revalidation. Historical candidate addresses are not configured automatically. No deployment or contract initialization is performed by API startup. The separate manual deployment script uses the preserved stateless deployer to deploy and initialize atomically, with CLI signing; it does not expose an uninitialized aggregator.

## Deployment record import

See [live integration readiness](LIVE_INTEGRATION_READINESS.md) for the actual contracts exporter schema, read-only `npm run import:contracts` procedure and remaining dependencies. The importer maps VELTRIXAE-compatible AMM IDs into the existing soroswap ABI slot; the separate veltrixae slot requires a real aggregator deployment. `npm run check:contracts-abi -- --repository /path/to/Contract` checks the exported binding signatures offline without executing source repository code. Neither command deploys or activates configuration.

The importer also accepts optional schema_version=1, the exact Testnet network_passphrase, version_source=cargo-package-version, per-contract version and upload_tx fields from the revised contracts exporter. Existing record formats remain accepted. A regression test rejects a mismatched passphrase. The completed deployment was imported and verified before activating the AMM configuration. Historical partial attempts remain provenance only; use the completed November 2 record.
